# mote

Original mote — ultra-compact GUI editor. Developer: **SYFaren**

Hard size budget, fixed feature set (no syntax/themes — see mote-x).

| Tree | Platform | Build |
|------|----------|-------|
| [linux/](linux/) | X11 | `cd mote/linux && make` |
| [windows/](windows/) | Win32 | `cd mote/windows && make` |

Extras vs bare nano-core: find next/prev, go to line, dup/del line, bracket jump, auto-indent, dirty open guard.

Sister folder: [../mote-x](../mote-x).
