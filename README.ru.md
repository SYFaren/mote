# mote

Маленький многоплатформенный текстовый редактор: **ядро на ANSI C89** и по
одному **оверлею** на платформу, выбираемому при сборке. Один и тот же редактор
работает окном X11, Wayland, SDL или Win32, в терминале, в консоли Windows, на
фреймбуфере Linux, под DOS и в браузере.

## Быстрый старт

```sh
make                 # Linux X11
make console         # терминал Unix
make test && make smoke
```

Другие порты: `make wayland`, `make sdl`, `make sdl3`, `make fbdev`,
`make win32`, `make winconsole`, `make dos`, `make wasm`. Подробнее в
[`docs/BUILD.md`](docs/BUILD.md).

## Возможности

### Файлы и документы

- До **6 документов** одновременно; номер виден в строке состояния как `[2/4]`.
- **Открытие** по пути (`Ctrl+O`). Несуществующий файл открывается как новый
  пустой. Неизменённый документ заменяется, а изменённый остаётся во вкладке, и
  файл открывается в новой.
- **Быстрое открытие** (`Ctrl+P`): файлы из папки текущего документа (до 256,
  по алфавиту, без скрытых) с нечётким фильтром — `edc` найдёт `editor.c`.
  Выбор стрелками, открыть — Enter.
- **Недавние файлы** (`Ctrl+E`): последние 8, сохраняются между запусками.
  Выбор цифрой 1–8, стрелками или j/k.
- **Перечитать с диска** (`F5`); при несохранённых правках редактор откажется.
- **Безопасное сохранение**: запись во временный файл, fsync, затем
  переименование поверх оригинала, так что сбой при записи не портит старый
  файл. Безымянный документ спросит имя.
- **Вопрос о несохранённых правках** при выходе, закрытии или открытии:
  `Ctrl+S` сохранить, `Ctrl+Q` отбросить, `Esc` отмена. При выходе сохраняются
  все изменённые документы, для безымянных сначала спрашивается имя.

### Текст, кодировки и концы строк

- Везде UTF-8: курсор и удаление работают целыми символами (кириллица, эмодзи).
- UTF-8 BOM при загрузке убирается.
- Файлы в **CP1251** (кириллица Windows) распознаются и переводятся в UTF-8.
- **LF / CRLF** определяются при открытии и сохраняются как были; одиночный CR
  становится LF. `Alt+E` переключает конец строки.
- Предел размера файла: 64 МБ (в DOS 2 МБ).

### Редактирование

- Отмена и повтор, 512 шагов на документ; набор подряд отменяется одним шагом.
- **Автозакрытие** `(` `[` `{` `"` `'`; при выделении пара оборачивает его.
- **Автоотступ**: Enter повторяет отступ текущей строки.
- **Tab** вставляет таб (ширина 4) или сдвигает вправо все выделенные строки;
  **Shift+Tab** сдвигает влево (один таб или до 4 пробелов).
- Дублирование и удаление строки, вырезать / копировать / вставить, выделить
  всё.
- **Комментирование** строки или всех выделенных строк в стиле языка:

  | Язык | Комментарий |
  |---|---|
  | Python, shell, YAML, Makefile | `# текст` |
  | SQL | `-- текст` |
  | CSS | `/* текст */` |
  | HTML / XML, Markdown | `<!-- текст -->` |
  | остальные | `// текст` |

  Если все непустые строки уже закомментированы, комментарий снимается.
- **Парные скобки**: пара у курсора подсвечивается, `Ctrl+]` прыгает к парной.
- **Только чтение** (`Alt+R`) запрещает любые правки, включая отмену; в строке
  состояния `RO`.

### Навигация и выделение

- Стрелки, Home / End, PgUp / PgDn; с Shift расширяют выделение.
- `Ctrl+←` / `Ctrl+→` — по словам.
- Вверх / вниз курсор помнит колонку, в том числе при переносе строк.
- **Переход к строке** (`Ctrl+G`).
- **Мышь** в оконных версиях: клик ставит курсор, Shift+клик и перетаскивание
  выделяют, колесо прокручивает.

### Поиск и замена

- **Поиск** (`Ctrl+F`): обычный текст, по умолчанию без учёта регистра;
  `Alt+C` — учитывать регистр, `Alt+W` — целое слово (оба запоминаются).
- **Регулярные выражения**: пишутся как `/шаблон/`. Есть `.` `*` `+` `?`,
  `^` `$` (начало и конец строки), `[...]` `[^...]` с диапазонами, `\d` `\w`
  `\s` и экранирование. Групп и альтернатив нет.
- `F3` / `Shift+F3`: следующее / предыдущее совпадение, по кругу через конец
  файла.
- **Замена** (`Ctrl+R`) заменяет все совпадения и сообщает их число. Обычный
  текст — замена для последнего поиска; `/что/на_что/` задаёт оба как регулярку.

### Закладки

- До 4 на документ, отмечены `*` у номера строки.
- `F8` ставит или снимает закладку на строке курсора; `F9` прыгает к
  **ближайшей** (при равном расстоянии — к нижней).
- Закладки следуют за своими строками при правках выше них.

### Вид

- Номера строк, подсветка текущей строки, строка состояния: имя файла, `*` если
  изменён, `RO`, строка:колонка, LF/CRLF, язык и последнее сообщение.
- **Перенос строк** (`Ctrl+W`), только визуальный; без него вид прокручивается
  по горизонтали.
- **Показ пробелов** (`F7`): `·` и `»` в окнах, `.` и `>` в текстовом режиме.
- **Темы** (`Ctrl+T`): dark, light, slate.
- **Масштаб** (`Ctrl+=` / `Ctrl+-` / `Ctrl+0`), 8–48 px, по умолчанию 15. В
  текстовых портах шрифтом управляет терминал.
- **Справка** (`F1`): в одну или две колонки в зависимости от ширины, с
  прокруткой.

### Подсветка синтаксиса

C/C++, Python, JS/TS, Go, Rust, Java, shell, SQL, PHP, JSON, HTML/XML (включая
SVG и plist), CSS/SCSS, Markdown, YAML и Makefile — по имени файла.
Подсвечиваются ключевые слова, типы и константы, строки (включая тройные
кавычки Python), числа, однострочные и блочные комментарии, препроцессор;
блочный комментарий, начатый выше экрана, учитывается правильно.

## Клавиши

В большинстве терминалов `Ctrl+Shift+буква` неотличима от `Ctrl+буква`,
поэтому у таких действий есть ещё клавиша с `Alt`.

### Файл

| Клавиша | Действие |
|---|---|
| `Ctrl+S` | сохранить |
| `Alt+S`, `Ctrl+Shift+S` | сохранить как |
| `Ctrl+O` | открыть |
| `Ctrl+P` | быстрое открытие |
| `Ctrl+E` | недавние файлы |
| `Ctrl+N` | новый документ |
| `F5` | перечитать с диска |
| `Ctrl+Tab`, `F2`, `Alt+N` | следующий документ (Shift / `Alt+P`: предыдущий) |
| `Ctrl+F4`, `Ctrl+Shift+W` | закрыть документ |
| `Ctrl+Q` | выход |

### Правка

| Клавиша | Действие |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | вырезать / копировать / вставить |
| `Ctrl+A` | выделить всё |
| `Ctrl+D` | дублировать строку |
| `Alt+K`, `Ctrl+Shift+K` | удалить строку |
| `Ctrl+/` | комментарий |
| `Tab` / `Shift+Tab` | сдвинуть вправо / влево |
| `Ctrl+]` | к парной скобке |

### Поиск и переходы

| Клавиша | Действие |
|---|---|
| `Ctrl+F` | поиск (`/re/` — регулярка) |
| `F3` / `Shift+F3` | следующее / предыдущее совпадение |
| `Ctrl+R` | замена (`/что/на_что/` — регулярка) |
| `Alt+C` / `Alt+W` | регистр / целое слово |
| `Ctrl+G` | к строке |
| `F8`, `Alt+M`, `Ctrl+Shift+M` | поставить / снять закладку |
| `F9`, `Alt+J`, `Ctrl+J`, `Ctrl+B` | к ближайшей закладке |

### Вид

| Клавиша | Действие |
|---|---|
| `Ctrl+W` | перенос строк |
| `F7` | показ пробелов |
| `Ctrl+T` | следующая тема |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | крупнее / мельче / сброс |
| `Alt+R`, `Ctrl+Shift+R` | только чтение |
| `Alt+E`, `Ctrl+Shift+E` | LF / CRLF |
| `F1`, `Ctrl+H`, `Alt+H` | справка (в терминале ещё F10–F12) |

## Командная строка и настройки

```text
mote [-h] [-v] [-H] [-g WxH] [файл ...]
  -h, --help         справка
  -v, --version      версия
  -H, --start-help   открыть справку по клавишам при запуске
  -g, --geometry     размер окна в пикселях (минимум 200x120)
                     или COLSxROWS в текстовых портах
  файл ...           открыть до 6 файлов
```

При выходе сохраняются: размер окна, тема, размер шрифта, перенос, показ
пробелов, параметры поиска и недавние файлы.

| Система | Файл настроек |
|---|---|
| Linux, BSD, macOS | `~/.config/mote/config` (или `$XDG_CONFIG_HOME/mote/config`) |
| Windows | `%APPDATA%\mote\config` |
| DOS | `MOTE\CONFIG` |

Переменные окружения:

| Переменная | Действие |
|---|---|
| `MOTE_START_HELP` | открыть справку при запуске |
| `MOTE_TRUECOLOR`, `MOTE_NO_TRUECOLOR` | терминал: включить или запретить 24-битный цвет |
| `MOTE_UTF8`, `MOTE_NO_UTF8` | терминал: включить или запретить вывод UTF-8 |
| `MOTE_FB` | fbdev: устройство фреймбуфера |
| `MOTE_VT`, `MOTE_NO_VT` | консоль Windows: VT-вывод вкл / выкл |
| `MOTE_KEYTRACE` | DOS: писать клавиши в `KEYTRACE.LOG` |
| `MOTE_DUMP_FB`, `MOTE_DUMP_CELLS`, `MOTE_SHOT_ONCE` | скриншоты для тестов |

## Платформы

| Порт | Где работает | Мышь | Системный буфер обмена |
|---|---|---|---|
| `x11` | Linux, BSD | да | да |
| `wayland` | Linux | да | нет (внутренний) |
| `sdl` / `sdl3` | Linux, BSD, macOS | да | да |
| `wasm` | браузер | да | да |
| `win32` | окно Windows | да | да |
| `winconsole` | консоль Windows | нет | да |
| `console` | терминал Linux, BSD, macOS | нет | вставка через `wl-paste` / `xclip` |
| `fbdev` | фреймбуфер Linux | нет | нет (внутренний) |
| `dos` | FreeDOS, DOSBox | нет | нет (внутренний) |

Терминальный порт сам выбирает truecolor, 256 или 16 цветов и принимает
bracketed paste. Горячие клавиши работают и на русской раскладке.

Релизные сборки: Linux amd64 / arm64 / armhf / i686 / riscv64 (включая
статические musl), FreeBSD, OpenBSD, macOS amd64 / arm64, Windows amd64 / i686,
DOS и веб.

## Структура и релизы

```text
core/       buffer, editor, keymap, utf8, undo, hl, regex, theme, config
plat/       platform.h
overlay/    x11 · wayland · sdl · fbdev · console · win32 · winconsole · dos · wasm
docs/       BUILD.md
scripts/    smoke, release helpers, install-local
```

`core/` обязан оставаться на C89 (`make ansi-check`); каждый оверлей добавляет
слой платформы. См. [`overlay/README.md`](overlay/README.md).

```sh
make release
sh publish-github.sh
```
