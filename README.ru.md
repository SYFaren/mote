# mote

Небольшой текстовый редактор с **ядром на ANSI C89** и подключаемыми при сборке
платформенными оверлеями. Сейчас поддерживаются POSIX-терминал (проверен Linux)
и консоль Windows; архитектура оверлеев позволяет добавлять другие порты.

## Быстрый старт

```sh
make                 # POSIX-терминал
make windows         # консоль Windows (MinGW-w64)
make test && make smoke
```

Поддерживаемые сборки: POSIX-терминал (`make posix`) и консоль Windows
(`make windows`). Общее ядро использует оверлеи платформ, поэтому позже можно
добавить другие порты. Подробнее в [`docs/BUILD.md`](docs/BUILD.md).

## Возможности

### Файлы и документы

- До **6 документов** одновременно; номер виден в строке состояния как `[2/4]`.
- **Открытие** по пути (`Ctrl+O`). Несуществующий файл открывается как новый
  пустой. Неизменённый документ заменяется, а изменённый остаётся во вкладке, и
  файл открывается в новой.
- **Быстрое открытие** (`Ctrl+P`): файлы из папки текущего документа (до 256,
  по алфавиту, без скрытых) с нечётким фильтром — `edc` найдёт `editor.c`.
  Выбор стрелками, открыть — Enter.
- **Недавние файлы** (`Ctrl+E`): последние 8, сохраняются между запусками.
  Выбор цифрой 1–8, стрелками или j/k.
- **Перечитать с диска** (`F5`); при несохранённых правках редактор откажется.
- **Безопасное сохранение**: запись во временный файл, fsync, затем
  переименование поверх оригинала, так что сбой при записи не портит старый
  файл. Безымянный документ спросит имя.
- **Восстановление после аварии**: после каждого изменившего данные пакета ввода
  изменённые документы записываются в отдельную копию рядом с конфигом
  (`config.recovery-N`, слоты 0–15). При запуске: `Enter` — восстановить,
  `Ctrl+Q` — удалить копию, `Esc` — выйти, сохранив её. Исходные файлы при
  восстановлении не перезаписываются: проверьте текст и сохраните явно.
  Безымянные документы и LF/CRLF восстанавливаются, undo и положение курсора —
  нет. Относительные пути становятся безымянными, чтобы не записать файл в другую
  рабочую папку. Восстановление имеет приоритет перед файлами из командной строки.
  Штатный выход удаляет копию своего экземпляра. Одновременные экземпляры занимают
  блокируемые слоты; если свободных нет, восстановление отключается с предупреждением.
  При ошибке обновления остаётся предыдущая копия и выводится предупреждение.
  Последний пакет ввода всё ещё может потеряться; гарантий от потери питания нет.
  Полные снимки могут замедлять ввод в больших файлах. Копии хранят открытый текст
  (права POSIX `0600`; в Windows наследуется ACL каталога конфигурации).
- **Вопрос о несохранённых правках** при выходе, закрытии или открытии:
  `Ctrl+S` сохранить, `Ctrl+Q` отбросить, `Esc` отмена. При выходе сохраняются
  все изменённые документы, для безымянных сначала спрашивается имя.

### Текст, кодировки и концы строк

- Везде UTF-8: курсор и удаление работают целыми символами (кириллица, эмодзи).
- UTF-8 BOM при загрузке убирается.
- Для файла с байтами вне ASCII, не являющегося корректным UTF-8, запрашивается
  подтверждение: `Enter` трактует его как Windows-1251 и переводит в UTF-8,
  `Esc` отменяет открытие без замены текущего документа. Это явный выбор, не
  распознавание кодировки: Latin-1 и другие кодировки сначала преобразуйте
  внешним инструментом. Сохранение пишет UTF-8, а не CP1251. Файлы с управляющими
  ASCII-байтами кроме Tab, LF и CR (включая NUL и DEL) не открываются как текст.
- **LF / CRLF** определяются при открытии и сохраняются как были; одиночный CR
  становится LF. `Alt+E` переключает конец строки.
- Предел размера — 64 МиБ на документ. Общего лимита на шесть вкладок нет;
  gap-буфер резервирует память примерно под размер файла, а история отмены
  хранит отдельные данные правок, поэтому пиковое потребление может быть заметно
  выше размера файла.

### Редактирование

- Отмена и повтор, до 512 операций на документ. Хранятся вставленные или
  удалённые фрагменты (дельты), а не снимки всего документа. Набор подряд
  отменяется одним шагом; крупные операции всё равно могут занять много памяти.
- **Автозакрытие** `(` `[` `{` `"` `'`; при выделении пара оборачивает его.
- **Автоотступ**: Enter повторяет отступ текущей строки.
- **Tab** вставляет таб (ширина 4) или сдвигает вправо все выделенные строки;
  **Shift+Tab** сдвигает влево (один таб или до 4 пробелов).
- Дублирование и удаление строки, вырезать / копировать / вставить, выделить
  всё.
- **Комментирование** строки или всех выделенных строк в стиле языка:

  | Язык | Комментарий |
  |---|---|
  | Python, shell, YAML, Makefile | `# текст` |
  | SQL | `-- текст` |
  | CSS | `/* текст */` |
  | HTML / XML, Markdown | `<!-- текст -->` |
  | остальные | `// текст` |

  Если все непустые строки уже закомментированы, комментарий снимается.
- **Парные скобки**: пара у курсора подсвечивается, `Ctrl+]` прыгает к парной.
- **Только чтение** (`Alt+R`) запрещает любые правки, включая отмену; в строке
  состояния `RO`.

### Навигация и выделение

- Стрелки, Home / End, PgUp / PgDn; с Shift расширяют выделение.
- `Ctrl+←` / `Ctrl+→` — по словам.
- Вверх / вниз курсор помнит колонку, в том числе при переносе строк.
- **Переход к строке** (`Ctrl+G`).

### Поиск и замена

- **Поиск** (`Ctrl+F`): обычный текст, по умолчанию без учёта регистра;
  `Alt+C` — учитывать регистр, `Alt+W` — целое слово (оба запоминаются).
- Все видимые совпадения подсвечиваются; текущее выделяется отдельно.
- `Esc` отключает подсветку поиска, сохраняя запрос; `F3` возобновляет поиск.
- **Регулярные выражения**: пишутся как `/шаблон/`. Есть `.` `*` `+` `?`,
  `^` `$` (начало и конец строки), `[...]` `[^...]` с диапазонами, `\d` `\w`
  `\s` и экранирование. Групп и альтернатив нет. Для буквального `/` используйте
  `\/`: например, `/a\/b/` ищет `a/b`. Текст замены вставляется буквально,
  без обработки regex-экранирования.
- `F3` / `Shift+F3`: следующее / предыдущее совпадение, по кругу через конец
  файла.
- **Замена** (`Ctrl+R`) заменяет все совпадения и сообщает их число. Обычный
  текст — замена для последнего поиска; `/что/на_что/` задаёт оба как регулярку.

### Закладки

- До 4 на документ, отмечены `*` у номера строки.
- `F8` ставит или снимает закладку на строке курсора; `F9` прыгает к
  **ближайшей** (при равном расстоянии — к нижней).
- Закладки следуют за своими строками при правках выше них.

### Вид

- Номера строк, подсветка текущей строки, строка состояния: имя файла, `*` если
  изменён, `RO`, строка:колонка, LF/CRLF, язык и последнее сообщение.
- **Перенос строк** (`Ctrl+W`), только визуальный; без него вид прокручивается
  по горизонтали.
- **Показ пробелов** (`F7`): `.` и `>` в зависимости от терминала.
- **Темы** (`Ctrl+T`): dark, light, slate.
- **Масштаб** (`Ctrl+=` / `Ctrl+-` / `Ctrl+0`), 8–48 px, по умолчанию 15. Это
  интерфейс для GUI-портов; текущие терминальные порты не меняют шрифт терминала.
  Старые протоколы клавиатуры терминалов часто не передают `Ctrl+=`, поэтому
  сочетание может не дойти до приложения.
- **Справка** (`F1`): в одну или две колонки в зависимости от ширины, с
  прокруткой.

### Подсветка синтаксиса

C/C++, Python, JS/TS, Go, Rust, Java, shell, SQL, PHP, JSON, HTML/XML (включая
SVG и plist), CSS/SCSS, Markdown, YAML и Makefile — по имени файла.
Подсвечиваются ключевые слова, типы и константы, строки (включая тройные
кавычки Python), числа, однострочные и блочные комментарии, препроцессор;
блочный комментарий, начатый выше экрана, учитывается правильно.

## Клавиши

В большинстве терминалов `Ctrl+Shift+буква` неотличима от `Ctrl+буква`,
поэтому у таких действий есть ещё клавиша с `Alt`.

POSIX-порт на время работы отключает программное управление потоком терминала,
поэтому `Ctrl+S` и `Ctrl+Q` обычно доходят до редактора. Мультиплексор или
удалённый терминал всё ещё может перехватить их; если сочетание не срабатывает,
измените настройки терминала или мультиплексора.

### Файл

| Клавиша | Действие |
|---|---|
| `Ctrl+S` | сохранить |
| `Alt+S`, `Ctrl+Shift+S` | сохранить как |
| `Ctrl+O` | открыть |
| `Ctrl+P` | быстрое открытие |
| `Ctrl+E` | недавние файлы |
| `Ctrl+N` | новый документ |
| `F5` | перечитать с диска |
| `Ctrl+Tab`, `F2`, `Alt+N` | следующий документ (Shift / `Alt+P`: предыдущий) |
| `Ctrl+F4`, `Ctrl+Shift+W` | закрыть документ |
| `Ctrl+Q` | выход |

### Правка

| Клавиша | Действие |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | вырезать / копировать / вставить |
| `Ctrl+A` | выделить всё |
| `Ctrl+D` | дублировать строку |
| `Alt+K`, `Ctrl+Shift+K` | удалить строку |
| `Ctrl+/` | комментарий |
| `Tab` / `Shift+Tab` | сдвинуть вправо / влево |
| `Ctrl+]` | к парной скобке |

### Поиск и переходы

| Клавиша | Действие |
|---|---|
| `Ctrl+F` | поиск (`/re/` — регулярка) |
| `F3` / `Shift+F3` | следующее / предыдущее совпадение |
| `Ctrl+R` | замена (`/что/на_что/` — регулярка) |
| `Alt+C` / `Alt+W` | регистр / целое слово |
| `Ctrl+G` | к строке |
| `F8`, `Alt+M`, `Ctrl+Shift+M` | поставить / снять закладку |
| `F9`, `Alt+J`, `Ctrl+J`, `Ctrl+B` | к ближайшей закладке |

### Вид

| Клавиша | Действие |
|---|---|
| `Ctrl+W` | перенос строк |
| `F7` | показ пробелов |
| `Ctrl+T` | следующая тема |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | крупнее / мельче / сброс |
| `Alt+R`, `Ctrl+Shift+R` | только чтение |
| `Alt+E`, `Ctrl+Shift+E` | LF / CRLF |
| `F1`, `Ctrl+H`, `Alt+H` | справка (в терминале ещё F10–F12) |

## Командная строка и настройки

```text
mote [-h] [-v] [-H] [-g WxH] [файл ...]
  -h, --help         справка
  -v, --version      версия
  -H, --start-help   открыть справку по клавишам при запуске
  -g, --geometry     COLSxROWS (40..300 x 10..120)
  файл ...           открыть до 6 файлов
```

При выходе сохраняются: тема, размер шрифта, перенос, показ
пробелов, параметры поиска и недавние файлы.

Конфигурация — обычный текстовый файл `key=value`. Например:

```text
theme=0
font_px=15
wrap=1
show_ws=0
find_case=0
find_word=0
```

Неизвестные ключи игнорируются. В текущих консольных портах `-g WxH` задаёт
размер сетки терминала (столбцы × строки), но не изменяет размер окна терминала;
хост может изменить размер окна или обрезать отображаемую сетку.

| Система | Файл настроек |
|---|---|
| Linux | `~/.config/mote/config` (или `$XDG_CONFIG_HOME/mote/config`) |
| Windows | `%APPDATA%\mote\config` |

Переменные окружения:

| Переменная | Действие |
|---|---|
| `MOTE_START_HELP` | открыть справку при запуске |
| `MOTE_TRUECOLOR`, `MOTE_NO_TRUECOLOR` | терминал Linux: включить или запретить 24-битный цвет |
| `MOTE_UTF8`, `MOTE_NO_UTF8` | терминал Linux: включить или запретить вывод UTF-8 |
| `MOTE_VT`, `MOTE_NO_VT` | консоль Windows: VT-вывод вкл / выкл |
| `MOTE_DUMP_CELLS`, `MOTE_SHOT_ONCE` | снимки сетки консоли Windows для тестов |

## Платформы

| Порт | Где работает | Мышь | Системный буфер обмена |
|---|---|---|---|
| `console` | POSIX-терминал (проверен Linux) | нет | вставка через `wl-paste` / `xclip` |
| `winconsole` | консоль Windows | нет | да |

POSIX-терминал сам выбирает truecolor, 256 или 16 цветов и принимает bracketed
paste. Горячие клавиши работают и на русской раскладке. Текущий фокус разработки
и релизов — POSIX и Windows console; архитектура ядра с оверлеями остаётся
расширяемой для будущих портов.

## Структура и релизы

```text
core/
  app/      жизненный цикл приложения и обработка аргументов
  document/ gap-буфер и история отмены
  editor/   состояние редактора, ввод и отрисовка
  syntax/   подсветка синтаксиса и regex-движок
  utils/    UTF-8, форматирование, темы и общие определения
  system/   конфигурация, карта клавиш и список файлов
plat/       platform.h (контракт оверлеев)
overlay/    console (POSIX) · winconsole (Windows)
docs/       инструкции сборки и релиза
test/       модульные тесты, клавиши, терминальный ввод и smoke-проверки
```

`core/` обязан оставаться на C89 (`make ansi-check`); каждый оверлей добавляет
слой платформы. См. [`overlay/README.md`](overlay/README.md).

```sh
make release
```
