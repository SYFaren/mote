## mote v2.1.1

Patch release: the Web build crashed on start in v2.1.0.

### Fixes

- **Web** — the editor state no longer lives on the stack; newer emscripten only gives 64 KB of stack and v2.1.0 overflowed it on start ("null function" in the browser console)
- Same change on every port (state is now static), which also gives DOS more stack headroom

See [v2.1.0 notes](v2.1.0.md) for what's new in 2.1.
