## mote v2.0.1

Patch release: fixed Linux cross builds and added **musl static** binaries.

### What's fixed / added

- **Linux glibc cross** — arm64, armhf, i686, riscv64 now ship **console, x11, sdl2** (v2.0.0 had console only on some arches)
- **Linux musl (static)** — `console` on arm64/armhf/i686/amd64; `fbdev` on amd64 (riscv64 musl N/A — no toolchain)
  - Flat names: `mote-linux-<arch>-musl-console`, legacy `mote-linux-musl-console` (amd64)
- **Download site** — glibc / musl filter on the Linux tab

Download site: **https://syfaren.github.io/mote-site/**

See [v2.0.0 notes](v2.0.0.md) for the full platform matrix and feature list.
