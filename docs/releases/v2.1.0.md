## mote v2.1.0

Help, keys and window fixes across all ports; every platform rebuilt.

### What's new

- **Help (F1)** — two-column key / action table grouped by File, Find, Bookmarks, Edit, View; fits 80×24, scrolls with arrows / PgUp / PgDn in narrow terminals
- **Same keys on every port** — F8 / F9 bookmarks and F2 / Shift+F2 next / previous file everywhere; Ctrl+/ comment on Wayland, SDL, fbdev and web; Ctrl+F4 close on X11
- **Bookmarks** — F9 jumps to the next mark below the caret (wraps to the top); status shows the line number
- **Wayland** — native window title bar and frame on KDE, Sway, Hyprland and other compositors with server-side decorations (GNOME stays undecorated)
- **Windows** — Vista-only APIs are now optional, so the binaries no longer require Vista to load (XP-compatible imports)

### Fixes

- Windows and console test builds with GCC 14
- Help box no longer covers the status bar
- Release CI: UPX-packed Linux binaries are copied correctly
