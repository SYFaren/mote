## mote v3.0.0

This major release refocuses active development and release support on two
console ports: POSIX terminal and Windows console. The shared core and overlay
contract remain extensible so additional backends can be added in the future.

### Changes

- **Supported builds** — POSIX terminal (currently tested on Linux) and Windows
  console, built with MinGW-w64 and using native Windows console APIs.
- **Overlay cleanup** — remove the X11, Wayland, SDL, framebuffer, Windows GUI,
  DOS and WebAssembly ports and their backend-only source assets.
- **Build and release** — simplify Make targets, CI and tagged GitHub releases
  to build/test the POSIX and Windows console binaries.
- **Maintenance tooling** — remove obsolete multi-platform release scripts and
  move smoke checks into `test/`.
- **Search** — highlight all visible matches, distinguish the current result,
  retain the query when dismissing search with Esc, and resume with F3.

### Upgrade notes

- This release no longer provides binaries for the removed GUI, DOS, framebuffer
  or WebAssembly ports. Existing historical release notes and Git tags remain
  available.
- `make` builds the POSIX terminal port. Use `make windows` for the Windows
  console cross-build (requires MinGW-w64).
- POSIX console build is verified on Linux; other POSIX systems may work but are
  not currently part of the tested release matrix.
