## mote v2.0.0

### What's new

- **Find & replace** — plain text and **regex**
- **Quick open** — go to file (`Ctrl+P`)
- **Line bookmarks** — F8 / Alt+B set, F9 / Ctrl+B / Alt+J jump
- **Console TTY** — escape parsing, modifyOtherKeys, protected status bar
- **Multi-arch release** — Linux (amd64, i686, arm64, armhf, riscv64), Windows (amd64, i686), DOS, WebAssembly

Download site (OS + CPU filter): **https://syfaren.github.io/mote-site/**

---

### Recommended download

**[`mote-all-platforms.zip`](https://github.com/SYFaren/mote/releases/download/v2.0.0/mote-all-platforms.zip)** — all binaries by folder + `flat/` + `SHA256SUMS`.

#### `by-platform/` layout

```
linux/amd64/{console,x11,sdl2,wayland,fbdev}/
linux/arm64|armhf|i686/{console,x11,sdl2}/
linux/riscv64/console/
windows/amd64|i686/{gui,console}/
dos/i686/
web/wasm/
```

Each folder contains `mote` (or `mote.exe`), optional `mote.upx`, and `README.txt`.

---

### Linux

| CPU | Backends | Flat names (examples) |
|-----|----------|-------------------------|
| **amd64** | console, x11, sdl2, wayland, fbdev | `mote-linux-console`, `mote-linux-x11`, … (legacy) and `mote-linux-amd64-*` |
| **arm64** | console, x11, sdl2 | `mote-linux-arm64-console`, … |
| **armhf** | console, x11, sdl2 | `mote-linux-armhf-console`, … |
| **i686** | console, x11, sdl2 | `mote-linux-i686-console`, … |
| **riscv64** | console | `mote-linux-riscv64-console` |

### Windows

| CPU | Backends | Flat names |
|-----|----------|------------|
| **amd64** | gui, console | `mote-windows-gui.exe`, `mote-windows-console.exe` |
| **i686** | gui, console | `mote-windows-i686-gui.exe`, `mote-windows-i686-console.exe` |

### Other

| File | Description |
|------|-------------|
| `mote-dos.exe` | FreeDOS / DOSBox (DJGPP); ship `CWSDPMI.EXE` from the zip alongside it |
| `mote-web.zip` | WebAssembly — unpack, open `mote.html` via a local HTTP server |
| `*.upx` / `*.upx.exe` | UPX-compressed variants |
| `SHA256SUMS` | checksums for all flat assets |

---

**Note:** Linux ELF binaries do not run on BSD/macOS. BSD builds: `make release-bsd` on FreeBSD/OpenBSD/NetBSD (not included in this zip yet).

ANSI C89 core; overlay is chosen at compile time.
