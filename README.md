# mote

Tiny GUI text editors by **SYFaren**.

One repo, two variants:

| Folder | Product | Budget |
|--------|---------|--------|
| [mote/](mote/) | Original — hard squeeze, fixed feature set | tens of KB |
| [mote-x/](mote-x/) | Extended — syntax, themes, line nums, replace, … | ~100–200 KB |

```sh
cd mote/linux && make && make test && make pack
cd mote-x/linux && make && make test && make pack
```
